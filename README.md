# SpeakFlow code

Native iPhone English word and sentence practice, using local audio and device speech recognition.

This independent code snapshot deliberately excludes private audio, practice banks, delivery records and previous project history. The original private project is retained separately. No permission to redistribute excluded sound assets is granted.

## Building

Use Xcode with the SpeakFlow scheme. The owner-operated manual workflow hydrates a hash-checked private resource snapshot before testing and compiling. Without authorized private resources the complete app cannot be built from this code snapshot alone.

Standard macOS GitHub-hosted runners are used. The workflow does not publish artifacts or releases to this repository. Private resources, build logs, screenshots and the unsigned IPA are delivered to a separate private repository. No Apple signing identity is stored here. Device installation and audio behavior require iPhone validation.
